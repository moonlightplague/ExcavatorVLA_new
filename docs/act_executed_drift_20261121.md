# 实际执行动作的累计偏差训练（2026-11-21）

本轮继续从velocity 8k优化，保持用户“全程模型动作、无任何接管”的边界。此前衔接版和记忆扰动版均没有证实稳定闭环收益，因此本轮不从这些候选权重继续叠加。

输出：`outputs/experiments/act_executed_drift_20261121_01`。

## 唯一新增训练项

沿用回程衔接版的128次预测片段、1500次更新、训练片段随机种子/采样、原回程/方向/实际执行前三步权重及源动作约束。原ACT核心冻结，只训练已有记忆模块。

每次预测的十步中，实际只执行前三步；新增项仅积分这三步的预测速度与专家速度差，按0.1秒步长，在连续8次决策（名义2.4秒）上计算累计命令关节位移误差。以训练动作标准差及窗口长度平方根缩放，损失系数0.05；回程与回转通道延续原有权重。存在padding的窗口不参与。

这是从原速度输出计算的训练损失，不增加位置动作头、位移规划器、运行时限幅/反向规则或纠偏控制。累计命令位移也不是实际物理关节位移；关节驱动/限位和闭环状态偏移仍须在模拟评估中检验。目标是检验减少持续速度偏差的训练约束能否改善长程动作，不预先宣称能修复撞限位或卡死。

与已有衔接版比较时只有此新增损失项不同，其他设置保持相同。新增验证指标是2.4秒执行命令累计位移误差；继续要求整体/回程首动作误差不超过源模型1.02倍、回程方向错误不超过源模型加1、bridge误差不增加，并要求全量累计位移误差不增加、回程累计误差不超过源模型1.02倍。

## 检查与后续
