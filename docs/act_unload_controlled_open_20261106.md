# 以57.5%组合作为基线：卸料保持的主动开斗兜底

用户选择回到`secure_align＋unload_pose_hold`，继续优化只修复了部分未入车情况的问题。默认评估入口`run_act_combined_random.py`的SOURCE逐文件核对与57.5%批次一致，`handoff_wait_source`默认None；新增等待是独立实验，从未设为默认，本轮明确不启用。工作区还有其他既有研究改动，不用旧归档覆盖它们。

57.5%原40场中，27场启动保持，23场成功。4场保持失败的首次启动前斗内分别70/41/68/62粒，预算均未耗尽；其中第16场末态仍有11粒，不能笼统描述为4场都已彻底卸空。第15/34场存在到位前留料损失，第16/21场最大已记录斗内量本就少于100粒。它们需要单独处理挖料/运输留料，不能靠延长保持产生额外物料。

另4场已验证对位但保持始终未启动，其中第10/13/28场交接时有155/135/138粒，ACT开斗命令约0.030/−0.037/−0.029rad/s，均低于原0.12触发阈值。现有保持只限制父关节，铲斗仍由ACT控制；如果ACT迟迟不开斗，保持不会接管。

本轮候选只给`unload_pose_hold`增加主动开斗兜底：原保持尚未启动、有料、位于原放料几何范围、`secure_align`已交还控制且实测完整开斗弧残差不超过原0.015m门槛时，启动同一个保持计时。父关节仍使用原逐步实测目标，兜底铲斗向已验证弧终点−0.4rad打开，速度最多0.8rad/s，并遵守原动作上限，不发出越过目标或反向闭斗的命令。退出仍为原50步计数或连续三次空斗观测，计时实现未更改。普通ACT触发的保持不改动。

这项候选在兜底分支明确接管铲斗动作，是执行层控制，不是ACT权重改进，也不是此前的20步交接等待。恢复、运输、原保料层及成功门槛不改。0.8rad/s小于原成功保持阶段正向ACT铲斗动作的第一四分位数约1.83rad/s，取较慢的固定值做首轮验证，结果出来后不在本轮调参。

实现为`scripts/act_unload_controlled_open.py`，只补丁实验私有源码，当前选定版继续保留。19项组件/快照/指标检查通过，覆盖开斗 admission、完整几何条件、动作上限/终点，以及“原任务仍成功但物料明显减少也必须拒绝”的约束。

开发物理验证目录`outputs/experiments/act_unload_controlled_open_20261106_01/`，问题场景10/13/28，原成功对照8/9/33，每场1个新的自主前缀。这3个对照在原记录中也存在交接不开斗情形，会实际受到新入口影响；未使用仅能验证未触发路径的成功场景。首次已验证交接或首次原保持启动前保存快照，随后原版、候选及重复原版各运行至多100步或原500步剩余时间。未到达者保留，不按结果换场景或追加前缀。

源码、协议和分析定义在首个分支前冻结。推进门槛：至少4对，其中问题/对照各至少2对且各至少有2对具备50步分支预算；问题平均固定斗内物料入车比例提高至少10个百分点，任务成功数至少多1；原成功来源对照的完成数不能下降，任何单个对照物料入车比例下降不能超过5个百分点；平均斗外且车外比例增加不超过2个百分点；重复原版入车比例差均不超过5个百分点。未通过则保留为实验候选，不升级，不删除不利样本。

沿用完整物理量恢复、同首帧/动作队列/RNG、固定快照斗内粒子ID和独立3秒落定观察。PhysX内部接触缓存和渲染历史未保存，重复原版量化其影响。既有真实40场场景均属已查看的开发数据，此轮不报告新总体成功率。结果见`REPORT.md`、`UNLOAD_REPORT.md`和`postflight_audit.json`，默认57.5%组合和27.5%历史基准均保留。

## 更合适的下一方向：卸料位置闭环，再保持开斗

源码复核确认，原对位轨迹检查使用当前load点和10个预测pour点，而不是完整物料出口。碰撞网格的扫掠复核发现：第9场这些参考点至车斗水平边界最小约14.5cm，但部分实体斗体扫掠越界约46.9cm；其余一些成功场景也有实体斗体外伸。因此这只是几何风险提示，不能把实体外伸直接等同于落料失败，更不能用事后挑选的阈值宣称本轮通过。

几何复核使用冻结碰撞模型278个去重点、10个开斗角度和实际车斗计数体，所有参考点与快照实测地标的最大一致性误差小于8×10⁻⁶米。方法和逐场边界值见`full_bucket_geometry_review.json`。未更改ACT观测地标，因为这些属于模型已训练的输入契约；后续应在执行层另外建立真实斗口的几何约束。

更合适的`unload_pose_hold`升级应把“参考点已入车”改为“有效卸料口及物料出口扫掠范围已安全进入车斗”：识别真实斗口和宽度，按当前姿态投影到车斗；偏边时保持闭斗，小幅校正父关节，逐步复核；有足够边界余量后再保持并开斗。对原本正常卸料的路径保持透传。真实斗口识别、微调控制和这一组合的独立物理验证尚未实现，不能称为已经验证的新版本。

第28场左右对比视频见实验`review/scene28_original_vs_controlled.mp4`，仅示意一组收益案例，完整6场含不利案例均保留。预定义几何汇总窗口可能包含卸料后动作，不将其中的漂移差值当作本候选收益证据。当前使用版保持`secure_align＋unload_pose_hold`，`handoff_wait`和本轮主动开斗候选均不启用。

独立审计通过：18次状态恢复，1339条前缀观测、1800条分支观测，最大恢复地标误差5.6513×10⁻⁶米；原基准826文件和57.5%批次419证据文件不变。启动前还核对55%批次462文件不变。两张GPU已释放。正式研究证据保留，未生成训练检查点或修改原成功门槛。
