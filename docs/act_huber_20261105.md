# ACT 新方案：用 Smooth L1 检验短转换动作的梯度分配

2026-11-05，用户要求继续寻找新方案。原27.5%基准固定，本轮只改变重建损失形式，原ACT结构、处理器、归一化、PHW权重、KL、数据与采样不变。

## 训练数据证据

入口 `scripts/audit_act_huber_gradients.py`，结果 `outputs/analysis/act_huber_gradient_audit_20261105_01.json`。使用此前固定清单中全部493个训练离土、215个训练持料观测和原PHW40k确定性预测，动作/padding/未来PHW权重按parquet核对；不使用验证或测试结果选损失参数。

持料训练观测的首步专家铲斗动作平均幅度0.5567 rad/s、中位数−0.4653 rad/s，92.1%幅度至少0.1 rad/s。因此不能把模型近零输出简单归因于持料首步专家标签大多为零。

在这215个观测的10步chunk中，前三步占加权归一化L1误差约93.9%，但仅占绝对输出梯度质量约52.1%。铲斗幅度至多0.03 rad/s的近零目标占该关节绝对输出梯度质量约60.8%。L1对很小的非零残差也给固定幅值梯度，使后续近零动作仍可能与短转换动作竞争更新。

固定候选为归一化单位下`Smooth L1(beta=0.1)`，导数幅度为`min(abs(error)/beta, 1)`。在同一缓存预测上估算，持料前三步的输出梯度份额约为80.0%，近零铲斗目标的份额约为13.3%。这是**输出梯度绝对质量的描述性计算**，不是实际参数梯度、训练后的预测，也不是根因或闭环收益的证明。相比只调整采样或增加阶段分类，该方案直接检验重建误差的梯度形式。

## 固定实验

入口 `scripts/run_act_huber.py`，损失实现 `scripts/act_huber_objective.py`。目录 `outputs/experiments/act_huber_20261105_01/`，训练前写入实际协议和来源哈希。

- 两组均从保留PHW40k启动，各400次参数更新、batch16、BF16、原新初始化AdamW、学习率1e-5、weight decay1e-4、梯度裁剪10；无调参网格。
- 同一70%全训练观测均匀＋30%按episode平衡离土/持料的有放回采样；两组完整样本顺序哈希必须一致。
- 对照使用原加权L1；候选使用全chunk、全关节的加权Smooth L1，beta固定0.1。有效PHW总权重分母、padding、原KL权重10均一致。不只修改阶段5/6的标签项，避免保留后续近零目标原有固定幅度梯度而削弱转换项。
- 不增加阶段输入、分类头或推理规则；导出仍为原ACT。两组仅保存第400步，原处理器文件逐字节复制并核验，终点重载检查。

训练集首步动作、状态、未来标签/权重与padding严格对齐，原数据/保留权重/冻结实验代码前后核对。单元检查覆盖原L1损失和全部参数梯度一致、小残差梯度下降而大残差梯度保持、padding/零权重/全屏蔽、分数权重的归一化尺度不变、beta非法值拒绝。

## 筛选与闭环

沿用1304个固定离线观测，包括全部22个持料验证帧；旧开发数据不当作独立测试。主门槛与上一轮相同：持料首步和转换前三步MAE相对原模型改善至少10%、相对同预算对照改善至少5%；各转换阶段不退化超过5%；其他阶段不超过`max(原MAE×1.05, 原MAE+0.002 rad/s)`；持料首步预测幅度至少恢复到专家的20%。

额外要求专家首步铲斗幅度至少0.1 rad/s的持料验证子集，其MAE同样改善至少10%/5%，且动作符号准确率相对原模型和对照均不下降，避免只靠预测幅度增大判成功。训练损失形式不同，不用两组各自的总损失数值直接排序。

全部门槛通过后，才运行事先固定的原40场第1、9、20、6场基准/候选配对闭环（最多8条），原`opening_pose`、−130°斗杆优先保料、500步、10Hz、PhysX、逐物理步渲染和成功条件不变。先查真实有料离土/起运、途中漏空及卸料，开发案例不报新独立成功率。

失败即按本轮预算结束，不更换beta、改门槛、加步数或追加大规模闭环。实验协议、日志与每组终点作为研究证据保留；测试临时模型/数据不落盘，输出和缓存由已有gitignore覆盖。

两组各完成400次更新，抽样顺序相同、处理器字节相同、终点重载及原输入哈希核对通过。每组仅保留第400步一个检查点。

| 持料首步预测幅度 | 0.011656 | 0.015557 | 0.099792 |

20个专家首步幅度至少0.1 rad/s的持料验证帧：原模型/对照/候选的首步铲斗MAE为0.446523/0.441873/0.380232，符号准确率为55%/65%/80%。候选持料首步MAE相对原模型下降14.6%，有局部效果；但持料前三步总MAE由0.042572增至0.048370，阶段1/2/7也出现退化，原九项门槛没有全部通过，状态为`completed_no_advance`。没有启动闭环、没有新成功率，保留27.5%基准。

### 单独声明的第二轮：保留实际执行前缀的L1

第一轮结束后的逐时刻检查发现，候选持料第0步的全关节MAE由0.10885降至0.09546，但第1/2步分别由0.01526/0.00361升至0.03002/0.01963；强脉冲改善伴随不该持续的后续动作。该分析用于生成新假设，不回改第一轮门槛或结果。

新一轮目录为`outputs/experiments/act_huber_prefix_20261105_01/`，入口加`--candidate-loss executed_prefix_l1`。对照仍为原L1，候选对原ACT实际会执行的前3步保留L1，对其余7步使用同一beta=0.1的Smooth L1；边界固定来自原`n_action_steps=3`，不搜索horizon或系数。两组重新从原40k开始各400步，不接着训练第一轮候选。数据、采样、PHW、KL、处理器、所有九项推进门槛和条件闭环案例均沿用，原研究记录不覆盖。
