# 回程强化后的挖料与运料优化（2026-11-19）

用户授权依据扩测结果沿当前方向继续优化模型，位置动作头已取消，不能重新排队。当前基线是 `act_training_alternatives_20261119_01/velocity/train/checkpoints/008000/pretrained_model`，八个新增场景中仅112完整通过十轮任务，其他场景表现为空载/低载荷、运料停滞或回程未完成。

闭环轨迹诊断：143、162在带料时回转接近 −π，末100步仍输出约 −0.091/−0.088 rad/s 的同向回转，几乎没有实际移动；50则在运料时反复调整铲斗。152后期已经空载，但仍未完成运料阶段。当前模型在专家轨迹拟合之外仍存在漂移恢复与任务进展表示问题。

本轮继续使用原140个训练 episode、20个验证 episode和相同的只读冻结特征缓存。不把扩测图像、状态或动作加入训练，不产生伪专家标签。原数据、原模型、原评估结果全部保留。

两组从基线精确转移已有权重，只训练 `model.memory_adapter.*`：

- `balanced`，追加8,000步：训练片段锚点按有效切入30%、带料阶段有效动作25%、回程15%、已有恢复标记20%、普通观察10%采样；某episode缺少该类锚点时退回普通采样。仍按原episode长度比例选父episode。片段包含48次预测，每步重建完整episode前缀后截断梯度。有效切入与运动中的带料观察损失权重3，回程权重2，已有恢复额外加1；前三个实际执行动作权重2，关节通道权重为[1.5,1.5,1.5,2]。在动作L1外增加0.15主动动作方向损失和0.15多步累积动作误差，直接约束原速度动作表示，不使用位置动作头。
- `progress`，追加12,000步：采用同样训练目标与采样，增加模型内部的关节角 sin/cos 特征投影和未来状态辅助头。角度由已有归一化状态恢复，投影零初始化，初始动作与基线逐值一致。辅助头从GRU表示预测四次决策（1.2秒）后的状态变化，包括4个关节位置、6个挖/倒目标相对几何分量和装料比例，共11维；Smooth L1系数0.05。缺失未来以及跨scoop/任务目标更新边界的样本不参与辅助损失。辅助头在推理时不控制动作，也不输入未来状态、阶段标签或任务计数。

AdamW初始学习率0.00007、余弦降至0.000007，weight decay 0.0001，梯度裁剪1，每批8段序列，每2,000步完整顺序验证。只保留每个候选最终checkpoint，并保存优化器及随机数状态。原视觉/Transformer/短历史核心保持冻结，每次训练结束逐张量比较。

候选选择仅使用20个验证episode上的固定分组指标：0.4×挖料首步MAE+0.4×带料首步MAE+0.2×回程首步MAE；同时要求总体首步MAE不超过基线1.2倍、回程首步不超过1.25倍，且分组加权分数改善。未通过者不自动部署到仿真。只选择通过条件且验证分数较好的最终候选。

随后自动进行三个开发回归场景：11（空载）、50（运料停滞）、112（原完整成功）。它们参与了问题诊断，因此不是独立留出测试；结果不能用于重新宣称未见场景成功率。固定十轮、5,000步、原种子、原成功标准，双卡并行录像，不在首例成功后提前停止剩余场景。

实现：`scripts/train_act_velocity_progress.py`、`scripts/check_act_velocity_progress.py`、ACT内部`persistent.py`。私有运行时为 `outputs/experiments/act_velocity_progress_runtime_20261119_01/python`，不修改已安装LeRobot或旧运行时。模型公开输入仍为三路RGB和28维当前状态，输出仍为十步四关节速度。阶段/恢复/回程标签只用于训练采样、损失和离线分组，不进入在线输入。控制器、仿真、任务阶段推进及成功判定源文件哈希保持不变。
