# ACT 卸料姿态保持：相同交接状态的开关对照

用户批准在相同卸料状态下对照开启/关闭姿态保持并重复运行。本轮不训练模型，原27.5%保留基准不替换。

入口为 `scripts/run_act_unload_ablation.py`，快照实现为 `scripts/act_unload_snapshot.py`。保持逻辑逐字节来自 `act_unload_pose_hold_20261106_01/validation8`，仅增加明确的布尔开关。闭斗、抬升、运输对位、原保料层、模型权重、处理器和动作时序在两组完全一致。

预先固定第7、16、29、33场，各3次全新仿真。每次先运行共同的自主前缀，在原保持逻辑第一次满足有料、开斗意图和释放几何时，于执行该步动作之前保存快照。不要求前缀复现旧沙粒轨迹，不使用结果选择交接点；500步内未到达合格状态或提前完成的案例明确记为未到达，保留在覆盖统计中，不更换场景。

快照记录全部沙粒位置与速度、机器人基座位姿和速度、全部关节位置/速度、积分命令目标，以及观测历史、阶段估计器、调度器和沙粒来源追踪。恢复后逐项检查，沙粒位置与速度要求哈希完全相同，机器人状态容差1e-5。客户端复制保料/脱困控制器状态、未执行动作队列和随机数状态。两组第一步均使用快照当时的同一真实图像，此后重新实时渲染和推理。

这是已观察物理状态的恢复，**不包含PhysX内部接触缓存与渲染器历史**，也不声称逐粒子确定性。两组都从恢复状态开始，顺序交替；每场第一份快照再重复一次关闭组，以量化相同策略恢复后的差异。若重复关闭组的入车比例差超过5个百分点，本轮不据此认定保持逻辑有效。

每个分支固定100步或原500步剩余预算，10Hz、原PhysX与逐物理步渲染不变；不因提前成功而缩短分支。完整任务仍要求至少100个原料堆粒子入车且斗角至少−0.8rad连续三观测。之后单独执行3秒零命令观察，不用它改变评分。

主指标以**快照时真实斗内的固定沙粒ID**为分母，统计固定终点的入车比例。另报仍在斗内、斗外且车外比例，三者守恒；后续新挖入的粒子不改变分母。对位指标为回转/大臂/斗杆各自角度漂移、剔除正常开斗旋转后的斗铰点XY漂移、预测开斗出料点距车斗水平投影的距离。保料层和保持逻辑是否实际修改动作逐步记录。

本轮在分支执行前固定推进条件：至少8个有效配对、覆盖至少3场；平均入车比例提高至少10个百分点，至少3场平均改善；平均斗外且车外比例增加不超过2个百分点；完整任务成功数不下降；重复关闭组入车比例差均不超过5个百分点。只要有一项失败就不推进，不改参数、场景或重复预算。所有场景已用于开发，结果不是新的整体成功率。

实验输出保留协议、源码哈希、物理快照、逐步记录、配对视频和研究报告；单元检查和快照接口探针的临时产物在检查后清理。输出与缓存沿用现有gitignore。

首批 `act_unload_ablation_20261106_01` 在共同前缀阶段停止，尚未保存卸料快照、运行分支或观察对照结果。检查安装版PhysX源码后，发现正常渲染步不保证回写当前沙粒速度；修正为快照保存前显式同步位置和速度，并新增恢复后的实测铲斗三点位置核对。该基础设施修正不改变控制器、场景、重复次数或门槛；首批停止原因单独记录。

第二批在启动核对时，仅因历史规划的`sample_try`元数据不同而停止；所有实际几何字段一致。修正比较时排除这个历史尝试序号，其他字段、初姿、指令及物理设置继续严格核对。两批及探针均未产生纳入对照的卸料结果，临时产物已清理，来源与停止原因保存在正式实验的`infrastructure_preflight_provenance.json`。

## 实际结果

正式目录为`outputs/experiments/act_unload_ablation_20261106_03/`。12次运行全部完成：8份快照可做相同状态配对，第7场第1/3次、第16场第1次及第33场第2次均在500步内未满足保持的启动条件，完整任务也未完成；这些案例没有更换或丢弃。

| 指标，仅8组有效配对 | 关闭保持 | 开启保持 |
| --- | ---: | ---: |
| 快照斗内固定粒子的平均入车比例 | 68.34% | 100.00% |
| 同批粒子平均斗外且车外比例 | 20.37% | 0.00% |
| 首次开斗期间平均最大斗铰点XY漂移 | 0.913 m | 0.469 m |
| 原完整任务完成数 | 5/8 | 7/8 |

入车比例在5组改善、3组相同、0组下降，平均提高31.66个百分点，中位提高1.43个百分点，收益并非在所有状态均匀出现。明显改善集中在第7场第2次、第29场第2次和第33场第3次：固定斗内粒子的入车比例分别由1.9%/0.8%/46.8%提高到100%。前两次把原任务失败变为成功；第33场关闭组已达到100粒任务门槛，但损失了本批物料约一半，开启后卸入更多物料。

第29场第3次快照只有76粒，开启后全部入车仍未达到原任务要求；保持物料入车与完成任务分别评分，不降低100粒门槛。所有比例仅以快照时斗内的固定粒子ID为分母，不宣称全程零漏料。4次未到达启动条件的失败也说明当前保持不能解决所有停滞、到位或开斗时机问题。

预先固定的六项推进检查全部通过。本轮支持将该保持逻辑保留为后续新场景验证的候选，不更新ACT权重，不替换27.5%历史基准，也不把开发配对的7/8报告为新的整体成功率。仍只有4个旧场景；场内重复具有相关性。首次开斗期间的姿态也没有完全锁定，第16场两次开启后的铰点漂移略大于关闭组，不能把平均改善写成每场都更稳。

18次分支恢复全部通过物理量核对，首步模型状态与预测一致；恢复后的铲斗三点位置最大误差约0.00000503 m。两份首轮合格快照上的重复关闭组，其终点入车比例差均为0；这只量化了这两份快照上的剩余仿真差异，不证明所有PhysX内部状态确定复现。逐项复算1758条分支记录，粒子ID守恒、动作限幅及原任务完成条件通过；原保留基准826个文件前后校验均未改变。5项单元检查及运动后恢复探针通过。

完整表格及全部分支视频见实验目录`UNLOAD_REPORT.md`；主指标和门槛见`REPORT.md`、`results.json`，几何分析见`unload_analysis.json`，最终核验见`postflight_audit.json`。第7场第2次左右对照视频为`review/scene7_repeat2_off_on.mp4`，左侧关闭、右侧开启；它是一个展示机制的正面案例，完整结论仍以全部预定案例为准。
