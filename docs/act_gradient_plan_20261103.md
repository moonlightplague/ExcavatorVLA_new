# ACT 下一轮方案：检验并处理持料监督的梯度干扰

状态：第一关已执行并结束，未达到预设启动门槛，未启动训练。机器可读约定见 `act_gradient_protocol_20261103.json`；执行前的完整约定保存在实验目录的 `protocol.json`，门槛未修改。

执行结果：两个前向随机种子的全参数强冲突批次为 8/16、6/16，计入 KL 的投影触发批次为 10/16、9/16。协议要求两种种子各至少 8/16 个强冲突批次，因此第一关未通过，后续 400 步训练、复验及闭环未启动。完整证据：`outputs/experiments/act_gradient_projection_20261103_01/REPORT.md` 与 `diagnosis_result.json`。

本轮仍解决“有料后不转运”。优先检验：在共享网络中，持料动作的监督更新是否与其他阶段的更新明显相抵。只有诊断支持这一假设，才比较普通更新与梯度投影更新；当前不认定梯度干扰就是根因。

## 依据与边界

- 原 PHW 40k 在 16 个训练观测上能拟合，200 步加权 L1 下降 63.6%。这说明这些标签可以学到，不能据此推断全部转换状态都容易拟合。
- 聚焦采样已把持料目标标签的预期监督质量从 2.38% 提高到 13.19%，但持料验证铲斗动作幅度仍仅 0.01251 rad/s，专家为 0.41046 rad/s。
- 同一方案的抽样卸料前三步/整 chunk 误差分别增加约 17.9% / 89.5%。共享参数更新的干扰值得检验；输入条件不足、标签歧义和短预算仍是未排除的解释。
- 阶段 6 的训练误差有约 94% 集中在前三步。现有证据不支持仅凭整 chunk 均值下降就判成功。

## 第一关：限额诊断，不更新权重

固定原 PHW 40k、保存的处理器和原 train/validation/test 划分，仅用训练数据定位。

1. 检查全部 215 个训练持料观测。从训练阶段 5–7 中分别寻找同 episode、不同 episode 的最近 5 个状态邻居，距离使用保存处理器得到的 28 维归一化状态。记录首步动作正负、幅度差及逐状态分量差。最多解码 8 对标签分歧明显的邻居图像，核对是否仍有视觉区别。状态相近不能直接判为完整输入不可辨识；检查训练历史时只取当前及过去帧。
2. 固定 seed 1000 的 70% 均匀 + 30% 阶段 5/6 采样序列，从前 64 个 batch 中取前 16 个同时具有持料/其他有效目标的 batch，每批 16 个观测；不足时报告诊断样本不足。样本清单先保存。
3. 每个 batch 使用一次原训练前向，保留原 dropout 与后验采样。根据**未来动作标签所属阶段**拆分持料 L1、其他阶段 L1 和 KL，分别取梯度。用两个固定前向随机种子 1000/1001 重复同一批次清单，最多 32 次带梯度前向，不执行优化器更新。
4. 记录全参数及动作头、状态投影、编码器、解码器、骨干各组的梯度范数、内积和余弦；单独报告 KL 与持料梯度的关系。分项损失沿用原全局有效权重分母，不能把短阶段另取平均后误报成原监督贡献。

启用实验的预设门槛：两个前向种子各至少 8/16 个 batch 出现持料 L1 与其他阶段 L1 的全参数向量梯度余弦小于 -0.1，且双方范数均大于 1e-10；同时各至少 4/16 个 batch 在计入 KL 后仍会触发下面的投影条件，避免启动一个几乎不改变更新的实验。该门槛是本轮的实验筛选约定，不是根因的统计证明；只出现 KL 冲突不满足此门槛。

若门槛未通过，本轮停止梯度投影分支并写出结果。若邻域审计提示输入条件不足，下一方案另行设计因果历史信息对照；本轮不同时增加历史输入或更换训练目标。

## 第二关：只改变梯度合成方式

通过第一关后，从相同原 PHW 40k 分别启动以下两组：

| 设置 | 普通更新对照 | 投影更新实验 |
| --- | --- | --- |
| 训练观测采样 | 固定 70% 均匀 + 30% 阶段 5/6 | 相同序列 |
| PHW 标签/权重、归一化、模型结构 | 原配置 | 相同 |
| chunk / 重规划 | 10 / 每 3 步 | 相同 |
| batch / 学习率 / weight decay | 16 / 1e-5 / 1e-4 | 相同 |
| KL 权重 / dropout / 梯度裁剪 | 10 / 0.1 / 10 | 相同 |
| 优化器 / 精度 | 新初始化 AdamW / BF16 | 相同 |
| 首轮 seed / 固定预算 | 1000 / 400 步 | 相同 |
| 更新差异 | 分项梯度直接相加 | 仅在负内积时投影持料梯度 |

这里的普通更新对照也使用 focused 采样。上轮 uniform 与 focused 同时改变了采样分布，不能拿两种分布作本轮更新算法的因果对照。

设原加权 L1 的共同分母为 `D = 4 * sum(valid * PHW_weight)`，按未来目标阶段 6 划分：

```text
L_hold  = 持料有效目标的加权绝对误差之和 / D
L_other = 其余有效目标的加权绝对误差之和 / D
g_hold  = grad(L_hold)
g_keep  = grad(L_other + 10 * KL)

普通更新：g = g_hold + g_keep

投影更新：若 dot(g_hold, g_keep) < 0 且 ||g_keep||² > 1e-20：
    g_hold = g_hold - dot(g_hold, g_keep) / ||g_keep||² * g_keep
    g = g_hold + g_keep
否则：g = g_hold + g_keep
```

投影按全部可训练参数的共同向量计算，不逐层各自改权重。合成后执行相同的原梯度裁剪、AdamW 和 weight decay。对照组也计算同样的分项梯度，保证反向计算量与随机数消耗可比。先在固定 batch 上核对分项相加与原损失梯度一致：float32 采用 rtol=1e-5、atol=1e-7；BF16 额外要求方向余弦至少 0.999、相对范数误差不超过 1%。不通过则先修复实现，不训练候选。

投影只是训练更新假设。AdamW 的预条件、动量和有限步长意味着它不能保证其他阶段无退化，仍须通过后面的实测门槛。未来阶段标签按 action 的相同时间戳和 episode 边界读取，两组采用相同的监督元数据路径。阶段标签只用于训练损失拆分，不作为策略输入；部署仍使用原 28 维状态与三路图像。

## 第三关：固定终点的离线筛选

两组都只保留第 400 步检查点。第 0/100/200/400 步可记录指标，但不选中间最佳点，也不根据曲线追加步数。先复用已冻结的 1,048 观测诊断清单；这是已经使用过的开发数据，不能视为新的独立测试。

进入复验必须同时满足以下预先约定：

- 全部 22 个持料验证观测的首步铲斗 MAE，相对原 PHW 40k 至少下降 20%，且相对同预算普通更新至少下降 10%。对专家首步铲斗幅度大于 0.1 rad/s 的观测，另算 MAE，也须达到这两个降幅。记录正负动作分组、方向准确率和预测幅度，不能仅凭动作幅度增大判成功。
- 离土验证首步铲斗 MAE，以及阶段 4/7/8/9 的抽样验证前三步全关节 MAE，相对原 PHW 与同预算对照均不得增加超过 5%。卸料整 chunk MAE 相对两者均不得增加超过 10%。其他阶段指标也完整记录。
- 原检查点/数据哈希未变，保存的处理器数值与功能一致，标签/padding 对齐、梯度有限、检查点重载均通过。

这些是进入下一关的工程筛选阈值，不代表 22 个验证帧足以证明稳定收益。首轮全部通过后，才用 seed 1001 从原 40k 重复一对各 400 步的训练；两种种子都必须通过。全部训练预算上限为 1,600 次优化器更新，不做其他参数网格搜索。

复验通过后，对完整的 20 个验证 episode 重新评估原 PHW、两个种子的对照与实验模型，复核上述保护阶段，并检查其他阶段是否有超过 10% 的前三步 MAE 退化。完整验证仍是开发评估；出现退化则不进入闭环。模型种子不择优：后续闭环固定使用 seed 1000 的第 400 步模型与其对照。
