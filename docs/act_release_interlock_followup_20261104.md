# ACT 释放前铲斗互锁：固定场景复核（2026-11-04）

后续 GPU 轮换重复复核已完成，结果见[平衡重复复核](act_interlock_gpu_balanced_20261104.md)：原 `opening_pose` 对照为6/10完成，互锁版3/10。互锁仍为显式可选项，默认关闭。

首轮 3 对开发案例显示互锁有局部收益，因此追加两组各 5 对的复核：第 8、16、34、38 场覆盖近车漏料、延迟交付和留料案例；第 6 场检查原成功场景。每场都固定相同原始几何、初始姿态、PHW40k 权重、−130°斗杆优先保料和500步上限；两版独立启动模拟器。seed/初始条件相同，不保证 PhysX 粒子轨迹完全相同。所选案例不是随机独立测试集。

## 当前设置与解释

评估 CLI 的 `--act-carry-release-interlock` 和调试 CLI 的 `--release-interlock` 默认关闭；只有明确指定才锁住释放前铲斗的积分开度目标。解除几何默认仍为 `load_point`，`opening_pose` 可显式指定。低层设置可用 `bucket_open_interlock=True` 单独开启。

“斗外/空中”计数不等同于地面接触散落，采样总量也会随运行变化。以上只能说明互锁不适合作为当前全局默认，不能推导它在所有场景无效。ACT 权重未改变；40场旧结果保持不动。
