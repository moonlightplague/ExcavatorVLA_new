# ACT脱困＋卸料保持：新随机40场

用户要求将`secure_align`和`unload_pose_hold`结合，直接测试随机40场成功率，不设对照。

正式目录：`outputs/experiments/act_combined_random40_20261106_01/`。入口：`scripts/run_act_combined_random.py`。所有场景与参数在第一场开始前冻结，seed为4100000–4100039。启动前核对未与现有ACT实验的seed清单重叠。

控制器、评估入口和几何模型逐字节复用`act_unload_pose_hold_20261106_01/validation8`的冻结版本，即刚完成同状态消融中开启保持的组合。模型仍为原PHW40k，处理器与归一化不变；原−130°斗杆优先、opening_pose保料层继续使用。脱困最长180步，卸料保持每次启动最长50步，具体阈值与源码哈希见`protocol.json`。

每场从初始状态自主运行，不使用旧动作、专家前缀、旧场景清单或快照恢复。使用原归档随机采样器生成料堆和车斗位置，初姿固定为原数据episode 0，与历史基准的随机评估一致。只保留原采样器在策略运行前执行的几何碰撞排除，不按结果重抽seed、不删除任务失败。

两张GPU各20场，每场全新模拟器。PhysX自由料堆、逐物理步渲染、10Hz、每3步重规划、500步上限。成功条件仍为至少100粒原料堆粒子入车，且斗角≥−0.8rad连续三次动作观测。本轮关闭评分后的额外零命令观察，不影响成功判据或评分时限。

分母固定40，未完成全批或出现基础设施错误时不发布最终成功率。每场保存视频、动作、三路相机哈希、来源计数和物理时序；独立从动作观测复算完成条件，并核对原生汇总器的成功数。原生汇总器的`official_result_valid`仅适用于无辅助的原始模型，本轮保留其原语义，另记录明确标注的组合策略成功率，不把混合控制结果标为纯ACT成绩。

模型与保留基准不替换，原基准826个文件启动前校验通过。新增2项检查覆盖新随机命令不继承场景回放，以及不足40场或包含基础设施错误时不生成最终成功率。单元检查使用临时内存数据，不留下测试模型或数据；正式结果作为用户要求的实验交付保留。输出沿用既有gitignore。

进度见`status.json`，逐场结果和最终成功率见`REPORT.md`、`results.json`，独立核验见`evaluation_audit.json`。

## 实际结果

40场全部完成，组合策略的本批成功率为 **57.5%（23/40）**：23场完整成功、17场未完成，基础设施错误0场。没有运行对照组，也没有重抽或替换失败场景。

28场触发了挖后脱困，27场触发了卸料姿态保持；这些是启用次数，不单独归因为对应优化的成功贡献。本轮只报告当前组合的成功率。

全部40个seed与预定清单一致，40份实际场景几何互不相同，每场视频完整。14,801条动作观测通过原成功条件和物理时序复算，原生完成计数与独立汇总一致。冻结模型/处理器/控制器等输入哈希不变，原保留基准826个文件前后校验不变。最终检查见`postflight_audit.json`，完整交付文件指纹见`evidence_sha256.json`。

ACT权重及27.5%历史保留基准没有替换。逐场成功/失败、入车数、接管和保持步数及视频链接见本实验`REPORT.md`。
