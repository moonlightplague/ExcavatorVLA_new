# 用户确认的模型能力边界（2026-11-21）

用户明确要求：结果必须来自模型能力，全程没有任何接管；在此范围内继续优化。

## 动作与任务环境的分工

模型根据既有三路RGB、28D状态及任务目标信息输出速度动作块，按原三步执行后重规划。学习到的GRU、投影、残差输出及正常归一化属于模型。示范标签和源模型输出可作训练监督，但评估运行时没有教师模型给动作。

测试环境设置起始场景、物理关节驱动和预先记录的每轮挖料/倒料目标，按物理事件计数并切换下一组目标。该目标切换不能替模型发出动作，结果表述为“给定作业目标下的模型动作控制能力”，不表述为模型自主选择每轮作业目标。普通关节驱动与物理限位仍存在。

以下任一情况不得计为符合本边界的模型成功：专家回放或前缀动作、外部状态机替代动作、护栏修改模型动作、卡死后的人工或自动救援、评估过程中重置姿态/记忆后继续拼接成绩、预测动作与发送给模拟器的动作有任何差别。每个episode开始的正常模型记忆清空属于原推理接口；中途不会按任务阶段清空记忆。

证明位于 `outputs/experiments/act_model_only_audit_20261121_01/audit.json`。这是这些记录中动作路径的证据，不是模型稳定成功率的证明。共享评估器有通用动作限幅代码，但本次核查的轨迹没有发生预测动作被限幅改写的情况。

## 后续训练与评价

保留原velocity 8k成功基准，仅修改模型结构、损失、采样、参数等训练内容；保留原数据划分，评估轨迹不回灌拟合。任何新模型必须通过动作审计后才能报告为符合此边界的成功。失败照实保留，不借助接管后继续累计成功轮次。

另核对了这35次轨迹内的196次目标切换：没有物理步推进、关节命令姿态改变或相机观察改变。源码中模型记忆仅在episode开始清空；切换下一组任务目标时不清空GRU记忆。目标变化后丢弃原目标下尚未执行的动作块并重新由模型预测。
